# Геоданные

При публикации GitHub Actions автоматически скачивает открытые векторные наборы Natural Earth и вырезает область Украины по bbox. В опубликованном сайте данные находятся локально в `data/`, поэтому браузер игры не зависит от CDN для этих слоёв.

Наборы: admin-1, populated places, roads, rivers/lake centerlines, lakes, coastline.
